# Meta Wearables Android samples

This repository contains three sample Android projects from the [Meta Wearables Device Access Toolkit for Android](https://github.com/meta/meta-wearables-dat-android):

- [`BirdSpotter`](BirdSpotter/README.md)
- [`CameraAccess`](CameraAccess/README.md)
- [`DisplayAccess`](DisplayAccess/README.md)

Each project has its own setup instructions. The upstream license and notice are included at the repository root.
